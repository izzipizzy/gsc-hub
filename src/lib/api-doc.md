# gsc-hub API

Базовый адрес: `{{BASE}}/api/v1`

## Авторизация

Каждый запрос несёт ключ в заголовке:

```
Authorization: Bearer <ключ>
```

Ключ выдаётся на странице `{{BASE}}/api` и начинается с `gsk_`. Показывается он один раз;
потерянный ключ не восстанавливается — создай новый и отзови старый.

Без ключа или с отозванным ключом ответ — `401 unauthorized`.

### Область ключа

У ключа может быть список сайтов. Тогда он видит **только их**: в списках чужие
property не появляются, а запрос с чужим `site` отвечает `404 site not found` —
для этого ключа такого сайта не существует. Ключ без списка видит все сайты.

Ключей может быть сколько угодно, у каждого своя область: один агенту на
испанский пул, другой подрядчику на один сайт.

## MCP-сервер

`POST {{BASE}}/api/v1/mcp`

JSON-RPC 2.0 поверх HTTP (Streamable HTTP, без SSE). Тот же ключ, тот же
заголовок. Подключение:

```
claude mcp add --transport http gsc-hub {{BASE}}/api/v1/mcp \
  --header "Authorization: Bearer <ключ>"
```

Методы: `initialize`, `ping`, `tools/list`, `tools/call`, `prompts/list`,
`prompts/get`. Уведомления (`notifications/*`) ответа не имеют — транспорт
отвечает `202`.

**Инструменты только читают статистику Search Console.** Ни склеек, ни покупок,
ни записи: ключ, отданный агенту, ничего не изменит.

| инструмент | что отдаёт | обязательные параметры |
|---|---|---|
| `list_sites` | сайты ключа с итогами за период | — |
| `site_queries` | запросы сайта | `site` |
| `query_pages` | страницы, ранжирующиеся по запросу | `site`, `query` |
| `striking_keywords` | позиции 4-20 с показами; без `site` — по всем сайтам ключа | — |
| `cannibalization` | запросы, по которым конкурируют свои же страницы | `site` |
| `ctr_benchmark` | CTR против ожидаемого по позиции | `site` |
| `decay` | просевшие страницы: свежее окно против предыдущего | `site` |
| `site_countries` | разбивка сайта по странам | `site` |
| `site_events` | склейки доменов и покупки ссылок с датами (чтение) | — |

Везде необязательные `days` (1..480, по умолчанию 28) и `limit`.

Ошибка инструмента возвращается как результат с `isError: true`, а не как сбой
протокола: модель видит текст и может исправить аргументы.

## Скилы

Готовые сценарии работы с этими инструментами. Забрать можно двумя способами.

**Как промпты MCP** — ничего скачивать не нужно: `prompts/list` и `prompts/get`.
В Claude Code они появляются командами `/mcp__gsc-hub__<имя>`.

**Файлами:**

```
GET {{BASE}}/api/v1/skills          # список
GET {{BASE}}/api/v1/skills/<имя>    # сам SKILL.md
```

Положить в `~/.claude/skills/<имя>/SKILL.md`, и скил станет обычным локальным.

## Подклеить домен к сайту

`POST {{BASE}}/api/v1/site-events`

Записывает, что домен-донор подклеен (301) к сайту в указанный день. Событие
появляется маркером «← донор» на графике сайта, на дашборде и в portfolio pulse, и в
общем списке склеек `{{BASE}}/events`.

Тело — JSON:

| поле | обязательно | что это |
|---|---|---|
| `site` | да | сайт, К КОТОРОМУ подклеили: `casino.com`, `https://www.casino.com/` или `sc-domain:casino.com` — всё одно |
| `donor` | да | подклеенный домен в любом из тех же видов |
| `date` | нет | день склейки `ГГГГ-ММ-ДД`; по умолчанию сегодня (UTC) |

Домены нормализуются: без схемы, `www`, пути и порта, в нижнем регистре. Кириллический
домен можно слать и как есть, и в punycode — это один и тот же донор; на графике он
подписан по-русски.

Пример:

```
curl -X POST {{BASE}}/api/v1/site-events \
  -H "Authorization: Bearer $GSC_HUB_KEY" \
  -H "Content-Type: application/json" \
  -d '{"site": "casino.com", "donor": "donor.com", "date": "2026-09-18"}'
```

Ответ:

```json
{
  "created": true,
  "event": {
    "id": 42,
    "siteHost": "casino.com",
    "date": "2026-09-18",
    "type": "merge",
    "note": "← donor.com",
    "addedAt": 1789750271625
  }
}
```

- `201` и `"created": true` — склейка записана.
- `200` и `"created": false` — такая склейка (тот же сайт, донор и день) уже была;
  возвращается существующая запись. Повторять запрос безопасно.
- `400` — не домен, донор совпадает с самим сайтом, или дата не настоящая. Текст
  ошибки говорит, какое поле не так.
- `401` — нет ключа или он отозван.

## Правила для агента

- Сайт, которого нет в `list_sites`, для этого ключа не существует: не угадывай
  property и не подставляй домен, которого не видел.
- Search Console показывает прошлое. Не обещай позиций и сроков.
- Один запрос — одна склейка. Несколько доноров — несколько запросов.
- Дата — день, когда склейка реально сделана, а не день, когда ты о ней узнал.
- Удалять склейки через API нельзя: это делает человек на странице сайта.
