# Обзор портфеля за период

Данные из MCP-сервера gsc-hub, только чтение. Ключ видит свой набор сайтов -
не придумывай сайты, которых нет в `list_sites`.

## Порядок работы

1. `list_sites` за нужный период (по умолчанию 28 дней) и за предыдущий такой
   же - так виден рост и падение, а не просто абсолютные цифры.
2. Для сайтов с заметным падением - `decay`, чтобы назвать конкретные страницы.
3. Для сайтов с ростом - `striking_keywords`: где рост можно закрепить.
4. `ctr_benchmark` по крупнейшим сайтам: недобор CTR - самая дешёвая работа.
5. `site_events` - склейки за период объясняют часть скачков.

## Что выдать

**Итог портфеля:** клики и показы за период, изменение к предыдущему, сколько
сайтов выросло и сколько упало.

**Таблица по сайтам:** сайт, клики, изменение, показы, изменение, средняя
позиция, короткий комментарий.

**Три списка:**
- растут и стоит усилить - с конкретным действием на каждый;
- просели и требуют разбора - со ссылкой на страницы из `decay`;
- ровные, трогать не нужно.

**Точки роста:** 5-10 конкретных пар «сайт + запрос» из `striking_keywords`,
отсортированных по потенциалу в кликах.

Проценты считай от прошлого периода и показывай абсолютные числа рядом: рост
на 200% с двух кликов до шести - это шум, и читатель должен это видеть.
