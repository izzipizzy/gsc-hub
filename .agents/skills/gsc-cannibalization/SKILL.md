# Каннибализация: кто с кем конкурирует и что с этим делать

Данные из MCP-сервера gsc-hub, только чтение.

## Порядок работы

1. `list_sites` - убедись, какой сайт доступен и о каком речь.
2. `cannibalization` по сайту за 28 дней. Инструмент вернёт группы: запрос,
   победитель и остальные страницы с их показами, кликами и позициями.
3. Для спорных групп - `query_pages` по конкретному запросу: там видно, как
   страницы делят показы и насколько разошлись позиции.
4. `site_events` - если домен недавно склеивали, часть дублей объясняется
   переездом, а не структурой сайта.

## Как читать группу

- **Один явный победитель, остальные глубоко внизу** - обычно не проблема.
  Google сам выбрал страницу. Трогать не нужно.
- **Две страницы рядом на 5-15** - настоящая каннибализация: они делят сигналы.
  Решение: оставить одну как целевую, вторую переписать под соседний интент или
  склеить редиректом.
- **Победитель меняется по гео** - смотри `site_countries`. Иногда это разные
  рынки, и страницы не конкурируют, а обслуживают разные страны.

## Что выдать

По каждой группе: запрос, страницы, их показы и позиции, вердикт (оставить как
есть / развести интенты / склеить) и одно предложение, почему. Отдельно -
список, который надо решать первым: там, где суммарные показы больше всего.

Не предлагай удалять страницы, по которым идут клики, без явной замены.
